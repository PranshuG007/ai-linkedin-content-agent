# AI-Powered LinkedIn Content Agent 🤖

An autonomous AI agent that researches data-industry topics, generates professional LinkedIn posts, formats them with emojis, selective bold text, real company tagging, and publishes them automatically using browser automation.

---

## 🚀 Features

- AI-generated professional posts  
- Smart hashtags  
- Real @company tagging  
- Emoji + emphasis formatting  
- Automated posting with Playwright  

---

## 🛠 Tech Stack

Python, OpenAI API, Tavily API, Playwright

---

## ⚙️ Setup

1. Install dependencies  
pip install -r requirements.txt

2. Create a `.env` file locally with:
OPENAI_API_KEY=your_key
TAVILY_API_KEY=your_key
LINKEDIN_EMAIL=your_email
LINKEDIN_PASSWORD=your_password

3. Run:
python main.py
